Objective
To analyze product return patterns and identify the categories, shipping methods, regions, and customer segments associated with the highest number of returns.

Analysis & Key Findings
- Office Supplies records the highest return count among the three product categories, followed by Technology and Furniture.
- Standard Class accounts for the largest number of returns among shipping methods, followed by Second Class and First Class.
- The regional chart highlights differences in return counts across regions, helping identify areas for further investigation.
= The Consumer segment contributes the largest share of returns, followed by Corporate and Home Office.
- Interactive slicers allow users to explore return patterns by segment, category, region, and year.

The dataset does not contain direct return reasons, so the dashboard identifies patterns rather than confirmed causes.
